# Judge walkthrough: hosted Chrome

Use [the hosted practice app](https://rollingtab.serverpod.space/play/) in Chrome. The [homepage](https://rollingtab.serverpod.space/) has a **Start playing** link to the same app. The published picker should show five scores. Choose Create account to verify your own email address and set a password. No shared credentials are needed when self-service is enabled.

1. Open the practice app. In **Studies & server repertoire**, choose **Choose server repertoire…** (or the adjacent **Choose server repertoire** cloud button). Select **Vals** by **Ferdinando Carulli** in the **Server repertoire** dialog. It opens paused at its recommended passage, with loop enabled.
2. Press **Play**. On first use, allow time for the score and SoundFont to load; **Initializing audio** shows progress. Chrome requires this direct Play gesture to enable sound. Expect the time display, Perspective TAB, and Now + next positions to advance with audible guitar synthesis.
3. Use **Speed** to enter or drag to **73%**. Playback should keep its pitch while slowing. If needed, press the repeat icon (**Enable loop** or **Disable loop**) so looping is on. Let the passage reach its end and return to its start.
4. Select **Save passage**. Choose Create account when prompted, enter your email, paste the verification code from your inbox, and set a password; existing users can sign in. Your passage settings are preserved. Give the passage a unique name, for example `Vals review <your initials> <date>`, and press **Save**. Expect the passage to appear as saved. Guest playback needs no sign-in; saving does.
5. Reload the browser tab. Open **My passages** and select the uniquely named passage. Expect **Vals** to reopen **paused**, at its saved bounds, with **73%** speed and loop still enabled. Press **Play** again if you want to hear it.

If first-use loading takes time, wait for the progress indicator to finish before retrying Play. Forgot password sends a recovery code. Codes expire after 15 minutes; resend is available after one minute, with at most three requests per email per hour across signup and recovery. The documented hosted guest playback was verified for the five-score release. If Create account is temporarily unavailable, use privately supplied fallback credentials; guest playback remains available.
